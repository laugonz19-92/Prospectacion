# 📊 Sheets Real-Time Dashboard 2026 EAN

Bienvenido al repositorio de documentación, prompts, roles y especificaciones técnicas para el **Sheets Real-Time Dashboard 2026 EAN**.

Este proyecto está estructurado de manera modular para permitir la colaboración eficiente entre humanos y agentes de Inteligencia Artificial (AI Pair Programming).

---

## 📁 Estructura del Sistema de Documentación

```text
.
├── README.md               # Este archivo: Índice general y guía rápida
├── PROMPT.md               # Prompt maestro de inicialización para el agente Orquestador
├── SKILLS.md               # Catálogo de habilidades, funciones utilitarias y tipos TypeScript
├── REQUIREMENTS.md         # Documento de Requerimientos de Producto (PRD), User Stories y DoD
├── ARCHITECTURE.md         # Arquitectura técnica, estrategia de polling en tiempo real y flujo de datos
├── WORKFLOW.md             # Matriz RACI, reglas de interacción y gobierno entre roles
└── roles/
    ├── ORQUESTADOR.md      # Especificación del rol: Orquestador Central / Cerebro
    ├── PRODUCT_OWNER.md    # Especificación del rol: Product Owner
    ├── UX_UI.md            # Especificación del rol: Diseñador de Producto y UX/UI Engineer
    └── TECH_LEAD.md        # Especificación del rol: Tech Lead / Software Engineer
```
